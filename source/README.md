# ひとたび (Hitotabi)

旅行の予定を時間順にひとつにまとめるアプリ。React + Vite。データはブラウザの localStorage に保存(現状は端末内のみ)。

```
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # dist/ に本番用ファイルを出力
```

## 仕様メモ
- 言語: アプリ全体を日本語/英語で切り替え(ヘッダー右上)。文言は `src/data.js` の `STR`。
- しおり: 終わっていない予定だけ表示。
  - 飛行機・電車(`AUTO_TYPES`)は到着時刻を過ぎると自動で消える。
  - ホテル・レンタカー・その他は「✓ 完了にする」で消える。
- 全旅程タブ: 消えた予定も含めて全部残る。
- 飛行機は便名・ターミナル・ゲート・予約番号、レンタカーは会社名・予約番号などを入力でき、予定に大きく表示。
- 時刻は各予定の現地タイムゾーンで扱う(`itemMs` / `arrivalMs`)。
- 「🔒 消さない」: 飛行機・電車が到着時刻で自動で消えないようにする(keep)。全旅程では「しおりに戻す」で復活。
- 「⚠ トラブル時」: 種類別の一般的な案内と、連絡先(電話)、この予定の後に影響しそうな予定(レンタカー・ホテル等)の連絡先を表示。自分用メモ(troubleMemo)も置ける。案内文は src/data.js の GUIDES。
